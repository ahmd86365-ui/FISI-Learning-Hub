# IT Technical

Location: IT → IT Technical (`/it/it-technical`).

Seven chapters, 28 lessons, 174 exercises, five selected derived images. Existing content renderers, cards, exercise reveals and search are reused. No separate progress system is introduced.

## Source scope

Authoritative source: the private `IT-Technik/` directory. Six PDFs (PC-Technik parts 1–3 and Tag 1–3), the Tag 5 presentation including speaker notes, and the photographed worksheets, answer keys, practice exam and USV guide were used.

Repeated fundamentals, mainboard/CPU/RAM explanations, firmware/POST, storage, USV and Windows material are merged by topic. Printed worksheet solutions are identified explicitly. Handwritten exam responses are not presented as official solutions. IMG_6116 is too blurred for reliable transcription; no missing text is invented. Lessons without source exercises say so.

Historical or inconsistent source values are identified in the relevant lessons, including storage conversion, binary subtraction, W/VA/Wh, USV rounding, firmware terminology, display tables and grouped Windows history rows.
